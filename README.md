# יונתן הנדימן

אתר של יונתן הנדימן: דף ראשי, 16 דפי ערים ו־8 מדריכים. הכתובת המתוכננת: yonatanhandyman.com

## איך האתר בנוי
- `tools/config.py` – פרטי העסק: טלפון, מייל, מחירים, שירותים, מדידה, ביקורות.
- `tools/cities.py` – התוכן של דפי הערים.
- `tools/guides.py` – התוכן של המדריכים.
- `tools/base.css`, `tools/extra.css` – העיצוב.
- אחרי כל שינוי מריצים `python3 tools/build.py` מתיקיית האתר, ומעלים את הכול. הבנייה גם בודקת שאין קישורים שבורים.
- לא עורכים ישירות את קובצי ה־HTML. הם נוצרים מחדש בכל בנייה.

## מה חסר לפני עלייה לאוויר
1. **טופס:** בליד הראשון מהאתר החי, FormSubmit שולח מייל אישור אל yonatanhandiman@gmail.com. צריך ללחוץ עליו, ועד אז הלקוח רואה הודעת שגיאה עם קישור לוואטסאפ ולחיוג.
2. **גיליון לידים:** הגיליון "לידים - יונתן הנדימן" כבר קיים בדרייב. נשאר להדביק בו את `tools/apps-script.gs` לפי ההוראות שבקובץ, ולמלא את `SHEET_ENDPOINT`.
3. **מדידה:** למלא את `ADS_ID`, `ADS_LABELS` ו־`GA4_ID`. כל עוד הם ריקים, לא נטען קוד של גוגל.
4. **תמונות:** לשים בתיקיית `img` את shelves, tv, furniture, doors, curtains, walls, bathroom, moving (קובצי webp), ובתיקיית `img/art` את kit, screwdriver, drill. עד אז מוצגים איורים, בלי כלים ברקע.
5. **רכז נגישות:** למלא את `ACCESS_COORDINATOR`.
6. **ביקורות, דירוג, שנות ניסיון ופרופיל העסק בגוגל:** למלא רק נתונים אמיתיים (`REVIEWS`, `RATING`, `RATING_COUNT`, `YEARS`, `SAME_AS`). כל עוד הם ריקים, הם לא מוצגים.

## העלאה לאוויר
- **Hostinger:** לחבר את המאגר הזה. הקובץ `.htaccess` כבר מכין את דף השגיאה וחוסם גישה לתיקיית `tools`.
- **GitHub Pages:** בהגדרות המאגר, בפרק Pages, לבחור את הענף `main` ואת התיקייה הראשית. הקובץ `CNAME` כבר מכיל את הדומיין.
- בסוף להגיש את `sitemap.xml` בכלי של גוגל לבעלי אתרים.
- דומיין אחר? לשנות את `DOMAIN` ב־`tools/config.py` ולבנות מחדש.
